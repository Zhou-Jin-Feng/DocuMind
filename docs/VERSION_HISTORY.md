## 使用边界

- 历史版本保留其对应的存储、界面和配置方式；不能以本页替代该版本的运行说明。
- 评测结论仅适用于对应数据、模型和配置，不代表所有语料或部署条件。

## 当前工作树与历史节点

主线使用 React/FastAPI，运行配置以项目根解析；历史 `v1.7.1` 则保留 Chroma/Gradio 架构，`v1.8` 完成Milvus迁移，`v1.9` 引入前后端分离。旧版使用其自带依赖与入口，不与当前运行方式混用。

本页列的是代码演进节点，不承诺每个节点都存在独立GitHub Release，也不把当前未发布工作树等同于某个历史tag。实际版本号以代码/运行服务为准，发布快照以对应引用为准。

## 3.1.0 源码候选（2026-09-21）

- 前端完成流式更新隔离、滚动所有权、可读性变量、统一弹窗与提示、正文引用定位、代码高亮和空状态引导。
- 当前条目描述源码候选与验证范围，不表示已有 Git tag、Release 或正式部署。
- 纯检索契约继续使用 Schema 1.0 / dense-v1；响应的 service_version 为 3.1.0。
- 结构化上下文候选的固定题集离线复核未提升完整证据单元 Recall@3，开发集 MRR@3 下降；未接入主线，Dense-only baseline 不变。
- 发布前检查记录见 [3.1.0 发布前检查记录](RELEASE_CHECK_3_1_0.md)；记录不表示已发布 Release。

## 3.0.0 新版变化

- 统一 React/FastAPI Web 入口，不再保留 Gradio 启动命令和旧 SERVER_* / SHARE_GRADIO 设置。
- 默认环境文件及相对应用运行路径以项目根解析，启动时创建必要目录；显式绝对路径继续有效。
- 常用评测工具默认把新报告写入 artifacts，固定数据与历史证据不作为日常输出覆盖。
- 纯检索契约继续使用 Schema 1.0 / dense-v1，响应的service_version为3.0.0。

这些变化需要按[迁移说明](MIGRATION_3_0.md)核对现有部署。版本标识只描述当前源码，不代替对应Release的实际发布与部署验收。
